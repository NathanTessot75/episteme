# Episteme

**Understand science at a glance.**

Episteme is a web app that turns any scientific article (PDF) into a clear, structured explanation generated by a language model. Drop a PDF and the app reads it, extracts the key concepts and explains it back like a teacher would, with a personal library, playlists and a social space.

---

## Features

- **AI analysis of PDFs**: upload a scientific article; the model extracts its key concepts and writes a pedagogical explanation
- **Paper search**: find related articles through the Semantic Scholar API
- **Personal library**: all your analysed articles in one place
- **Playlists**: organise articles into thematic collections
- **Explorer**: discover articles shared by other users
- **Profiles and messages**: follow other readers and exchange with them
- **Researcher verification**: link a ResearchGate or university profile, reviewed in an admin dashboard
- **Dark mode** and smooth page transitions (Framer Motion)

---

## Tech stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19, Vite, React Router |
| Styling | Tailwind CSS, Framer Motion |
| PDF parsing | pdf.js |
| Backend, auth and database | Supabase (PostgreSQL, row-level security, storage) |
| AI and search | OpenAI API, Semantic Scholar API (through serverless proxies) |
| Hosting | Vercel |

## Run locally

```bash
git clone https://github.com/NathanTessot75/episteme.git
cd episteme
npm install
```

Create a `.env` file at the root:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

# Server-side keys used by the proxies in api/ (set them in Vercel too)
OPENAI_API_KEY=your_openai_key
SEMANTIC_API_KEY=your_semantic_scholar_key   # optional
```

```bash
npm run dev
# → http://localhost:5173
```

The database security rules are in [`supabase/`](supabase/), to run in order in the Supabase SQL editor.

## Project structure

```
api/                 Serverless proxies (OpenAI, Semantic Scholar), deployed on Vercel
src/
├── Pages/           Home, Explorer, Library, ArticleDetail, PlaylistDetail, Profile,
│                    UserProfile, Messages, Auth, AdminDashboard
├── Components/      Sidebar, SearchBar, ArticleCard, Timeline, modals…
├── Context/         AppContext (global state, AI logic), AuthContext
├── Services/        OpenAI and file (PDF) services
└── Entities/        Article and ResearchQuery models
supabase/            SQL scripts: storage security, verification, admin
```
